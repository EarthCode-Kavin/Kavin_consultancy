# SEO Quick Reference - Action Items

## 🚨 IMMEDIATE ACTIONS REQUIRED

### 1. Update GitHub Pages URL
**Find and Replace in these files:**
- `index.html` (multiple locations)
- `robots.txt`
- `sitemap.xml`

**Replace:** `https://yourusername.github.io/website/`
**With:** Your actual GitHub Pages URL

Example: `https://your-github-username.github.io/your-repo-name/`

### 2. Create Social Media Image
- **File:** `og-image.jpg`
- **Size:** 1200 x 630 pixels
- **Content:** TerraSight logo + tagline + geology imagery
- **Location:** Root directory (`e:\website\`)

### 3. Generate Favicons
Use https://favicon.io/ to create:
- `favicon-32x32.png`
- `favicon-16x16.png`
- `apple-touch-icon.png`

Place in root directory.
